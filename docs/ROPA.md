# ROPA — Registro de Operações de Tratamento de Dados Pessoais

**Projeto:** Banco de Personagens CriaLab|UEG
**Controlador:** CriaLab|UEG — Laboratório de Pesquisas Criativas e Inovação em Audiovisual (UnU Goiânia-Laranjeiras)
**Versão:** 1.0 — agosto/2026

| Campo | Registro |
|---|---|
| **Finalidade** | Conectar temas de produção audiovisual a pesquisadores, laboratórios, equipamentos e pesquisas da UEG, para pré-produção de filmes/programas de divulgação científica. |
| **Bases legais (LGPD)** | Art. 7º, III (políticas públicas de ensino/pesquisa/extensão); art. 7º, IV (estudos por órgão de pesquisa, com anonimização quando possível); art. 7º, §4º (dados manifestamente públicos). |
| **Categorias de dados** | Nome, vínculo institucional, e-mail funcional @ueg.br, URL pública de Currículo Lattes, ORCID, produções acadêmicas. **Nenhum dado sensível** (art. 11) é tratado. |
| **Titulares** | Docentes, pesquisadores e servidores da UEG com dados já públicos nas fontes. |
| **Fontes** | BDTD/UEG (acesso aberto), Dados Abertos GO/CKAN (CC-BY), páginas institucionais ueg.br, OpenAlex (CC0). |
| **Destinatários** | Uso interno da equipe CriaLab (pré-produção). Sem cessão a terceiros; sem publicação em massa de contatos. |
| **Retenção** | Enquanto o dado permanecer público na fonte e útil à finalidade; registros brutos retidos para auditoria após opt-out. |
| **Direitos do titular** | Canal de opt-out na própria interface (página "Privacidade (LGPD)"); remoção da interface e das sínteses após solicitação. |
| **Segurança** | Sistema local, sem exposição pública; credenciais fora do código; minimização (exibir só o necessário à finalidade). |

*Manter este registro atualizado a cada nova fonte ou nova funcionalidade que trate dados pessoais.*
